# token-radar

A web dashboard ranking tokenless protocols by implied value: a 198-row board (40/40 watchlist covered) with market-calibrated multiples and a 7-step farm plan per row, plus a dark dashboard with search, filters, and detail views.

## Run it

```sh
node main.ts
```

## The files

- `dashboard/`: the dashboard (index.html, app.js, app.css).
- `lib/model.ts`: the ranking model with market-calibrated multiples.
- `main.ts`: the harness driver (unchanged from the kit).
- `vendor/makefun-board.ts`: kept as the kit ships it.
- `screenshots/`: three screenshots of the dashboard.
- `out/`: generated output (board.json, dossier.json, dashboard, screenshots) — regenerated by running main.ts.
